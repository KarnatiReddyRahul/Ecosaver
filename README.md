# 🌍 EcoSaver – Smart Energy Consumption Dashboard

EcoSaver is a Streamlit-based web application designed to monitor, analyze, and visualize energy consumption data in an interactive and user-friendly way. The project helps users track energy usage patterns and promotes smarter energy management using real-time analytics and dashboards.

---

## 🚀 Features

- 📊 Interactive Energy Dashboard
- 🔥 Real-time Data Visualization
- 📈 Energy Usage Analytics
- 🗂 MongoDB Database Integration
- 🌐 Streamlit Web Application
- 📉 Graphs and Performance Metrics
- 💡 User-friendly Interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- MongoDB
- Pandas
- Plotly
- NumPy
- PyMongo
